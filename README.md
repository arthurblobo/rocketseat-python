# rocketseat-python

Este repositório reúne os códigos que desenvolvo durante a trilha de Python da Rocketseat. Aqui ficam os exercícios, exemplos das aulas e projetos práticos, organizados por módulo na ordem em que avanço no curso.

O objetivo é construir uma base sólida na linguagem, partindo dos fundamentos, como variáveis, estruturas de controle e funções, até temas mais avançados, como orientação a objetos e desenvolvimento de aplicações. Cada pasta representa uma etapa da trilha, então o histórico de commits também funciona como um registro da minha evolução nos estudos.
